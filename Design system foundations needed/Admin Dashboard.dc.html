Decisions on this console
Rejection costs more than approval, so it costs more effort. Approving is one tap with a summary; rejecting requires typing REJECT — the confirm button stays disabled until it matches. Suspending a store sits between: a confirmation, no typing, because it is reversible. Liability is the platform's headline risk. Outstanding points are money the network owes, so the figure is pinned in the rail and repeated under the chart rather than hidden in a report. The queue is a first-class destination. Pending applications carry a count in the app bar and a badge on the rail item — an admin should never have to go looking for work that is waiting. Same charts, same rules as the owner console. Teal issued, deep-accent redeemed, three gridlines, tabular figures, bars in a fixed plot area so height is always proportional to value. Nothing new was invented for admin.
