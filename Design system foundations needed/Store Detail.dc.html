Decisions on this screen
Your standing comes before the store's story. Balance and stamp progress sit directly under the name, above rewards and details — a returning customer's first question is "what have I got here?", not "what is this place?". One pinned action. Show my code stays in the thumb zone on glass; scroll passes behind it. Subscribe is inline and only shown when relevant, so the pinned bar never changes meaning. Details are opt-in. Rewards / How to earn / Details is a segmented control rather than a long scroll, and opening hours collapse to a single "Open now" row — practical detail on request, never in the way. Desktop reflows, it doesn't rescale. The image goes full bleed across the frame, the same blocks become a 3:2 two-column layout with three stat cards in place of the stacked balance card, and the mobile segmented control moves to the right column carrying the same three panels, hours dropdown included. On desktop this page is read-only for subscription and for the QR code — redeeming is the only action here; subscribing and presenting the code stay on the phone, where they physically happen at the counter. Type scale is unchanged. Unsubscribe is quiet and reversible-looking. Outlined, at the bottom, turning red only on hover — destructive-adjacent, but this one doesn't need a confirmation because points survive unsubscribing.
