How the two views relate
Glass is chrome only. App bar, bottom nav, desktop top bar, sheet and dialog are translucent with content scrolling behind them; every surface holding money — balance, rewards, activity rows — stays opaque. When a sheet or dialog opens, the chrome drops to an opaque background so no two blur layers compound. Same destinations, same order. Bottom nav at 390 becomes the left rail at 1280 — five items, identical labels and icons. The rail adds a persistent balance block because the width is free. Width buys density, not size. Type scale and colour roles are identical. Activity rows go 48px → 40px and gain a separate timestamp column; rewards move from stacked cards to compact rows; the balance card lays out horizontally instead of stacking. One state. Both frames read the same store subscriptions, stamp count and points, so redeeming in the phone updates the desktop rail live. Confirmation is a bottom sheet on mobile and a centred 460px dialog over a full-frame scrim on desktop — both driven by the same state, so either surface can complete the redemption and both frames update.
